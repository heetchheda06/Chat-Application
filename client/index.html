Core Functionality

Engineered for Real-Time Wireless Transmission

Demonstrating all standard networking requirements of Wireless Mobile Communication.

Real-Time 1-to-1 Chat

Instantaneous full-duplex communication between two wireless stations using WebSocket events with millisecond latency.

Group Broadcasting

Simulates wireless multicast where a single packet sent from user A is distributed to all registered group nodes simultaneously.

Online/Offline Presence

Socket heartbeat packets track connection drops and signal status changes dynamically across all connected wireless nodes.

Chat History & Persistence

Persistent message storage with MongoDB & Mongoose (plus transparent local fallback) keeps past packets preserved after refresh.

Wi-Fi & 4G/5G Compatibility

Seamless communication across devices connected to the same WLAN access point, or across different IP subnets on mobile carriers.

Secure Authentication

Industry-standard password encryption with bcryptjs and stateless access management via JSON Web Tokens (JWT).
