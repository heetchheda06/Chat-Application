Networking Foundation

Communication Protocols in WaveChat

The core networking technologies powering real-time client-server communication.

OSI Layer 7
HTTP / HTTPS
Stateless Request-Response Protocol

Used for initial authentication (registration and login), fetching historical chat logs, uploading user profiles, and establishing the primary handshake with the server.

  • Half-duplex request-response cycle
  • Encrypted via TLS/SSL (HTTPS)
  • Used for REST API endpoints
OSI Layer 7
WebSocket / Socket.IO
Full-Duplex Bidirectional Channel

Provides real-time packet delivery without continuous polling overhead. Once the initial HTTP handshake upgrades to WebSocket, both server and client can transmit instantly.

  • Persistent low-overhead TCP connection
  • Event-driven architecture (`private_message`)
  • Sub-millisecond transmission latency
OSI Layer 4
TCP / IP
Reliable Stream Transport

Underneath both HTTP and WebSockets lies TCP (Transmission Control Protocol), which guarantees that every message packet reaches the destination in exact sequence without loss.

  • Three-way handshake (SYN, SYN-ACK, ACK)
  • Automatic packet retransmission on error
  • Port-based multiplexing (Port 3000)
OSI Layer 1 & 2
Wi-Fi (IEEE 802.11)
Local Wireless Area Network (WLAN)

Enables laptops and smartphones within the same radio range to associate with a wireless Access Point (AP) or router. Devices obtain local IPv4 addresses (e.g. 192.168.x.x) and exchange frames via radio frequencies (2.4 GHz or 5 GHz).

College Demonstration: Running WaveChat on one computer allows any mobile phone or second laptop connected to the same Wi-Fi SSID to communicate seamlessly using the computer's local IP address.
Cellular WAN
4G LTE / 5G Cellular Networks
Wide-Area Mobile Packet Service

When WaveChat is deployed to a cloud server (or exposed via port-forwarding / ngrok), mobile devices connect through cellular base stations (eNodeB / gNodeB) over 4G/5G mobile Internet across different geographic locations.

Core Advantage: Demonstrates high-speed mobile packet data, low-latency 5G network slicing, and ubiquitous client-server connectivity even when devices are miles apart.
